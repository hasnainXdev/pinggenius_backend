# Data Model: LinkedIn Outreach Generation

## Overview
This document defines the data models for the LinkedIn outreach generation feature, including entities, attributes, relationships, and validation rules.

## Entity Models

### LinkedIn Profile
- **Entity Name**: LinkedInProfile
- **Description**: Represents the target's LinkedIn profile with extracted information
- **Fields**:
  - id (ObjectId): Unique identifier for the profile record
  - url (string): The original LinkedIn profile URL
  - role (string): Current role of the profile owner
  - company (string): Current company of the profile owner
  - industry (string): Industry/ICP signals from the profile
  - recent_activity (string): Recent activity information (optional)
  - created_at (datetime): Timestamp when the profile was analyzed
  - updated_at (datetime): Timestamp when the profile was last updated
- **Validation Rules**:
  - url must be a valid LinkedIn profile URL (FR-001)
  - role, company, and industry must not be empty (FR-002)
  - created_at and updated_at must be valid timestamps
- **Relationships**: 
  - One-to-many with OutreachSequence (one profile can generate multiple sequences)

### Outreach Sequence
- **Entity Name**: OutreachSequence
- **Description**: A collection of four messages generated for a specific LinkedIn profile
- **Fields**:
  - id (ObjectId): Unique identifier for the sequence
  - profile_id (ObjectId): Reference to the associated LinkedInProfile
  - connection_note (string): The connection request message
  - dm_1 (string): First direct message
  - follow_up_1 (string): First follow-up message
  - follow_up_2 (string): Second follow-up message
  - tone (string): The tone used for generation (Friendly, Direct, Authority, Casual)
  - created_at (datetime): Timestamp when the sequence was generated
  - updated_at (datetime): Timestamp when the sequence was last updated
- **Validation Rules**:
  - All message fields must be under 200 characters (SC-003)
  - All messages must be personalized, short, non-salesy, and platform-aware (FR-004)
  - tone must be one of the specified options (FR-005)
  - profile_id must reference a valid LinkedInProfile
  - created_at and updated_at must be valid timestamps
- **Relationships**:
  - Many-to-one with LinkedInProfile (multiple sequences can be generated from one profile)
  - Contains multiple Message entities (the individual messages)

### Tone Preference
- **Entity Name**: TonePreference
- **Description**: User-selected parameter that influences the style and language of generated messages
- **Fields**:
  - id (ObjectId): Unique identifier for the tone preference
  - name (string): The name of the tone (Friendly, Direct, Authority, Casual)
  - description (string): Brief description of the tone characteristics
  - created_at (datetime): Timestamp when the preference was created
- **Validation Rules**:
  - name must be one of the predefined tone options (FR-005)
  - description must not be empty
  - created_at must be a valid timestamp
- **Relationships**:
  - Used by OutreachSequence to determine message generation style

### Message
- **Entity Name**: Message
- **Description**: An individual component of an outreach sequence
- **Fields**:
  - id (ObjectId): Unique identifier for the message
  - sequence_id (ObjectId): Reference to the parent OutreachSequence
  - content (string): The actual text content of the message
  - position (integer): Position in the sequence (1-4: connection_note, dm_1, follow_up_1, follow_up_2)
  - created_at (datetime): Timestamp when the message was created
  - updated_at (datetime): Timestamp when the message was last updated
- **Validation Rules**:
  - content must be under 200 characters (SC-003)
  - content must be personalized, short, non-salesy, and platform-aware (FR-004)
  - position must be between 1 and 4
  - sequence_id must reference a valid OutreachSequence
  - created_at and updated_at must be valid timestamps
- **Relationships**:
  - Belongs to one OutreachSequence

## State Transitions

### LinkedIn Profile States
- **NEW**: Profile URL submitted but not yet analyzed
- **ANALYZING**: Profile is being processed to extract context
- **ANALYZED**: Profile has been successfully analyzed
- **FAILED**: Profile analysis failed due to accessibility or other issues

### Outreach Sequence States
- **GENERATING**: Sequence is being generated by the AI
- **GENERATED**: Sequence has been successfully created
- **REFINING**: Sequence is being refined based on user feedback
- **REFINED**: Sequence has been updated based on feedback

## Data Relationships

```
LinkedInProfile (1) <---> (Many) OutreachSequence
OutreachSequence (1) <---> (Many) Message
TonePreference --> OutreachSequence (used for generation)
```

## Indexes

- LinkedInProfile.url: Unique index for efficient lookup
- LinkedInProfile.created_at: Index for time-based queries
- OutreachSequence.profile_id: Index for efficient profile-to-sequence lookups
- OutreachSequence.created_at: Index for time-based queries
- Message.sequence_id: Index for sequence-to-message lookups
- Message.position: Index for ordering messages within a sequence

## Data Privacy Considerations

- All personal data from LinkedIn profiles should be stored in compliance with GDPR
- Implement data retention policies to automatically delete old records
- Provide mechanisms for users to request deletion of their data
- Only store the minimum necessary data required for functionality (FR-011)
